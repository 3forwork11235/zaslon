# Заслон

Тактический 3D-шутер (Unity, WebGL): 10 видов оружия, 6 карт, 5 режимов, кампания, боты и онлайн по ссылке-приглашению.

Играть: https://3forwork11235.github.io/zaslon/

Онлайн: «Играть → Онлайн с друзьями → Создать», отправьте другу ссылку-приглашение. Вкладка создателя комнаты должна оставаться открытой.

Управление: WASD — бег, мышь — обзор, ЛКМ — огонь, ПКМ — прицел, Shift — спринт, C — присесть, Q/E — наклон, R — перезарядка, Esc — пауза.

Шрифт интерфейса — Inter (SIL Open Font License 1.1, https://github.com/rsms/inter). Сетевой слой: PeerJS (MIT) и MQTT.js (MIT).
